# 阅读器可靠性与界面调整

本节描述 0.4.3 及之前的阅读器可靠性重构；这些调整保留 Kotlin / Compose、完全离线和现有书库资源格式，用户数据库版本为 6。0.4.4 – 0.4.6 的变化见文末「后续调整」。

## 状态归属

- `ReaderApplication` 持有 Repository 与排版偏好，Activity 重建不会新建一套数据容器。
- 导航返回栈通过 `listSaver` 保存，页面和首页标签分别使用 `SaveableStateHolder` 保存状态。
- `ReaderDestination` 提供页面范围的 `ViewModelStore`。退出阅读页后释放完整正文引用，剩余正文缓存仍由 Repository 的四本书缓存管理。
- 搜索与书架分别使用 `SearchViewModel`、`ShelfViewModel`。书架订阅数据变更，笔记标记订阅独立的笔记变更，翻页保存进度不会反复加载笔记。

## 数据写入

- 书签操作等待写入完成后返回实际添加或移除结果；失败显示错误信息。
- 全书和章节进度在一个 SQLite 事务中更新，任一步失败都会回滚。
- 用户写入使用同一个串行调度器与互斥锁。进度保存由应用范围任务执行，以便页面退出时提交；进程被系统立即终止时仍不能保证尚未执行的写入完成。
- `readerOperation` 仅将普通异常转换为可展示错误，取消异常继续传播。
- 首次搜索索引由应用范围共享任务建立，取消某次查询不会取消整个索引。索引仍在现有数据库中，长事务与阅读写入的竞争需要实机测量后决定是否进一步隔离存储。

## 阅读位置与排版

- 按钮、正文左右点击、目录和搜索跳转共用位置转换函数。
- 滚动模式先恢复目标位置，再订阅滚动位置；分页模式先恢复锚点，再保存已停稳页面的位置。
- 退出或进入后台时通过最新状态引用提交位置，避免依赖旧的回调捕获。
- `withNoteAnchors` 将笔记字符范围投影到已经排好的页面，高亮或批注变化不会重新调用 `StaticLayout`。

## 界面方向

0.4.3 预览版改为中性浅色与深色背景、红色强调和统一圆角。启动器及应用标识恢复马克思头像。书库直接展示搜索、继续阅读和作者；书架保留阅读、书签、笔记摘要；设置按排版、外观、数据和关于分组。去除宣传语和重复离线说明，来源信息可展开查看。护眼与系统主题继续使用对应的语义颜色。

## 后续调整（0.4.4 – 0.4.6）

- 0.4.4：阅读工具栏改为覆盖在固定正文区域之上，开合菜单不再改变分页尺寸，底部预留导航空间；滚动模式按原文字符和实际文字行恢复，并支持左右滑动切换章节；分页计算移至后台，连续排版调整合并、过期任务在计算检查点取消，滚动模式不生成分页；正文书 LRU 缓存上限 4 本，分页缓存上限 3 章或 60 万字符，并预排下一章（章节超过 60 万字符时跳过预排）；合并连续阅读位置写入，离开阅读器或切入后台时立即提交最新位置。
- 0.4.5：分页器与正文文字控件启用备用字体行高，分页边距按单边像素取整后再相加；修复分页模式页内纵向滚动和点击原文注释误翻页；原文注释改用实际文字布局的命中范围并增加 8dp 容错。
- 0.4.6：仅修订内置文库正文内容（来源导航行、重复结构标题行、私有使用区字符与源页字节帧错位），App 代码与界面无改动。

正文完整性规则与当前基线见 [LIBRARY_QUALITY.md](LIBRARY_QUALITY.md)。

## 验证入口

```shell
gradlew.bat testDebugUnitTest assembleDebug assembleDebugAndroidTest lintDebug
```

连接安卓设备后运行 `gradlew.bat connectedDebugAndroidTest`，并检查长章节跨章跳转、分页与滚动切换、旋转后返回路径、小屏及大字体、夜间模式和密集笔记。JVM 测试与测试 APK 编译不能替代设备上的交互与视觉验证。
