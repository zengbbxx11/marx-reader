# 马列原典 v0.4.6-preview.20260910

versionCode：`14`，从 `0.4.5-preview.20260908`（versionCode `13`）顺延。本次不涉及界面与阅读逻辑改动，仅修订内置文库的正文内容。

## 本次更新：正文完整性清理

第二轮正文核查发现三类此前未被门禁覆盖的缺陷，连同《资本论》第三卷的字节帧错位一并订正：

- **来源导航行**：`上一篇 / 回目录 / 下一篇` 等组合型导航文本被当作正文保留，共移除 **149 处**。
- **重复结构标题行**：来源页把卷/篇/章标题作为普通文本行输出，而 App 已单独渲染 `chapter.title`，导致正文首段重复，共移除 **196 处**，并同步重映射 **195 个 `section`** 的 `paragraphIndex`。
- **私有使用区（PUA）字符**：GBK 用户区字节按错误字符集解码后落入 U+E000–U+F8FF，按显式映射表还原 **40 处**（`　`、`ö`、`ä`、`志`、`米`）。
- **字节帧错位（《资本论》第三卷）**：此前判为「不可逆」的 10 个 PUA 字符实为源页把汉字首/次字节写成 ASCII `?`（`0x3F`）导致的双字节整体错位，信息仍在。经**源页原始字节取证 + 书库字频模型判别 + 本卷权威英文译本核对**，确认仅 **3 处错位、真正丢失 5 个汉字**（特、是、来、呢、与），其余正文与源页逐字一致，未使用回译。订正后全库 **不再有任何 PUA 字符**。

### 门禁规则变更

新增三条 `ERROR` 级规则，并清空 `PUA_UNRESOLVED` 白名单：

- `NAVIGATION_LINE`：正文出现来源导航行；
- `DUPLICATE_STRUCTURE_HEADING`：正文窗口内出现与本作品标题集或当前章节标题一致的结构行；
- `PRIVATE_USE_CHARACTER`：正文出现私有使用区字符（原先 10 个已知字符的豁免已删除，任何 PUA 字符一律计为错误）。

## 数据与验证

清理后正式内置文库为：

- 650 部作品或文本版本，884 个章节，1,935 个 `section`；
- 56,140 个正文段落（原 56,485，减少 345 = 149 导航行 + 196 结构标题行）；
- 8,672,713 个正文字符；
- 质量门禁 `ERROR=0`，默认 `REVIEW` 由 1,487 降至 **1,477**。

**章节 ID、`section` ID 与 `sourceUrl` 全部保持不变**，用户既有的阅读进度、书签与笔记不会失效。

订正表固化在 `tools/repair_source_shift.py`（默认 dry-run，`--apply` 才写入），已在 `.generated/library-full.pre-fix3.json` 留底后重打包资源；重复执行幂等。
