# 0.4.5-preview.20260908

versionCode：13。修复分页模式下页内纵向滚动及点击原文注释误翻页。

- 分页器与 TextView 在 Android 9 及以上均启用备用字体行高，避免中文实际高度高于分页估算。
- 分页边距按单边像素取整后再相加，与 Compose 正文容器一致。
- 分页模式固定原生正文滚动位置；滚动阅读模式仍由外层列表滚动。
- 页码移入底部预留空间，避免覆盖正文末行。
- 原文注释采用实际文字布局的空间命中范围，四周增加 8dp 容错；优先处理注释，再处理普通正文点击。
- 点击坐标纳入原生文字控件滚动偏移，轻微手指移动仍保留按下时命中的注释。

《共产党宣言》（marx-work-6523f0586337）的 48 处注释引用经静态检查均有效。新增点击范围单元测试，并将该书的多字号、多字体分页高度及注释定位加入设备回归测试。

44 项单元测试全部通过；应用与设备测试 APK 构建、lint 及签名验证通过。lint 仅保留已有的单色主题图标警告。

设备测试需在 Android 真机或模拟器运行；本地环境无已连接设备，因此本次未实测手机上的排版高度和点击手感。预览版使用 Debug 签名。

实现依据：[Android StaticLayout 备用字体行高说明](https://developer.android.com/reference/android/text/StaticLayout.Builder#setUseLineSpacingFromFallbacks(boolean))、[Android TextView 源码](https://android.googlesource.com/platform/frameworks/base/+/main/core/java/android/widget/TextView.java)。
