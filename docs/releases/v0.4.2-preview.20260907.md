# 马列原典 v0.4.2-preview.20260907

这是面向 GitHub Releases 的预览版本，基于上一版 `v0.4.1-preview.20260831` 继续开发。

## 本次更新

- 恢复旧版酒红底、米色打开书本启动器图标。
- 优化阅读进度与章节进度写入，失败时保持事务一致性。
- 修复重复操作书签时提示与实际结果不一致的问题。
- 改善搜索取消、首次索引构建、页面恢复和阅读器 ViewModel 生命周期。
- 笔记高亮变化不再触发整章重新分页。
- 增加书库概览、继续阅读入口、书架摘要和书籍封面式标识。
- 统一暖纸色、酒红强调色、间距、圆角和阅读底栏样式。

## 下载与验证

上传 GitHub Release 时使用以下文件名：

`marx-reader-0.4.2-preview.20260907.apk`

该 APK 为离线 Debug 预览包，不请求 `android.permission.INTERNET`。正式发布前请使用受控的发布密钥重新构建签名包。
