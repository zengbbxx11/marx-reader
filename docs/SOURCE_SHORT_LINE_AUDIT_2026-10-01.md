## 原因、记录与验证

`tools/build_full_chinese_library.py` 的 `keep_text()` 丢弃长度小于 2 的行；标题处理也会删除单字符 ASCII 标题。源 HTML 中的原始换行可能把一个表格单元格或字词拆成单字行，这些字符在浏览器里仍属于正常表格或句子。修复时应按明确的表格／标题／原注释上下文保留短行，不能直接放开所有单字行而把导航等噪声重新导入。

新增只读工具：`tools/audit_source_short_lines.py`。复跑命令：

```bash
python tools/audit_source_short_lines.py --pending-tables docs/SOURCE_REPAIR_PROGRESS.json
```

需要安装现有 Python 工具依赖，并先采集 `.generated/source-audit-20261001/` 中的原始源页证据。换设备查看本轮已核查结果不需要缓存，直接读本报告和 [修复进度](SOURCE_REPAIR_PROGRESS.md)。27 个表格已从“待核查”改为“已确认待修”，新增条目附源 URL、上下文与源摘要；后续不用重复确认同一个问题。

85 项 Python 测试通过，原有 53 条已修复记录及 77 个资产摘要校验仍通过。本轮是核查与记录，正式文库内容保持此前修复版本；不表示全库完成逐句译文或纸本校勘。
