# 内置书库注释修复

本次扫描全部 650 部作品、884 个章节，在 36 部作品中恢复 971 处有正文的注释引用，
另为2处源站缺文的编号增加明确标注的可点击缺文说明，合计增加973处可点击入口。
其中《资本论》第一卷 21 处、第二卷 81 处、第三卷 266 处；《共产党宣言》27 处，
《第二国际的破产》15 处，《英国工人阶级状况》73 处，
《无产阶级革命和叛徒考茨基》38 处，《雇佣劳动与资本》91 处。
其余变更及逐项待核对记录见 [机器可读报告](footnote-repair-report.json)。

## 原因与处理

- HTML 导入只匹配 `_ftn` / `_etn`，漏掉了 Word 实际使用的 `_edn` 尾注。现在兼容这三种格式。
- 老页面的正文编号、章末注释可能完全没有 HTML 链接。新增打印式注释恢复逻辑，
  支持章末多段注释、独立注释章、多个编号共用注释、空白缩进、编号独占一行、
  粘连的注释标题及明确的行内圈号译注。
- 作者注 `[80]` 和编者注 `【80】` 属于不同编号系统，分别匹配。
  重复圈号按局部位置匹配；跨章编号必须有明确作用域，冲突时不自动关联。
  内置《资本论》第二、三卷的编者注使用全卷编号，包含跨章及附录引用。
- 已有 HTML 锚点注释优先保留。修复不改正文字符、段落、章节 ID、目录、阅读位置数据。
  安装包的现有内容指纹生成任务会自动纳入修复后的书库。
- 打包流程也运行恢复逻辑，避免以后重建书库时重新丢失这些关联。
  注释审计现在既检查已存在的引用位置，也检查存在正文却遗漏关联的打印式注释。
- 网页漏载的注释通过 [校补记录](../tools/library_footnote_supplements.json) 恢复 130 处。
  每条记录包含书目、章节、段落、字符范围、整段 SHA-256 和来源页码。
  原文变动时会拒绝套用过期位置，要求重新核对；原有 HTML 引用优先保留。

## 来源及仍未解决的两处标记

文章内容以 [中文马克思主义文库](https://www.marxists.org/chinese/) 为准。
本次实际纳入书库的校补来源全部来自该站；没有纳入其他网站的扫描件内容。

- 《资本论》第三卷原先缺失的 `[131]`、`[133]`、`[190]`、`[192]`、`[194]`
  已依据该站 [全集第25卷下册](https://www.marxists.org/chinese/pdf/marx-engels/me25b.pdf)
  PDF 第533、540、541页补齐。
- 《无产阶级革命和叛徒考茨基》依据该站
  [列宁全集第35卷](https://www.marxists.org/chinese/pdf/lenin/collectext/J75.pdf)
  补齐页下注及两条尾注。重复引用同一段话时，按实际正文位置和页码配对。
- 《雇佣劳动与资本》新增的校补依据该站
  [2012年选集第1卷](https://www.marxists.org/chinese/pdf/marx-engels/mes01.pdf)。
  这是按所注词句核对的不同中文版本，不能仅按编号套用。
  校补注释的显示内容明确注明版本、PDF页码以及译词和编号差异；正文保持原样。
- 四处独立注释标签或对别篇文献注释的引用不属于缺失的正文入口，
  已在校补记录的 `exclusions` 中逐条注明理由，并同样验证原文段落哈希。

目前仍有两处无法确认，均在《雇佣劳动与资本》：

1. 段落107，start=77，句末“高利贷者和挥霍者相互制约一样”后的②。
2. 段落125，start=63，引文中“生产性劳动力”后的③。

源站 HTML 未提供这两处定义，现有对照版本不能明确证明它们指向哪条注释。
保留原文字及待核对记录；点击显示“【源站注释缺文】”、明确的缺文说明及源站地址，
不把提示当作原书注释。数据以 `status=SOURCE_MISSING` 区分，反复修复和审计仍报告这两处缺文。
因此，本轮扫描查出的正文编号不可点击问题已处理，但不能称为全部源文缺失已经解决。
位置使用从0开始的索引，完整上下文见机器可读报告。

## 验证及维护命令

在安装 `tools/requirements.txt` 所列依赖的 Python 环境运行：

```text
python -m unittest discover -s tools/tests
python tools/repair_library_footnotes.py
python tools/repair_library_footnotes.py --apply
python tools/audit_footnotes.py app/src/main/assets/library
python tools/audit_library_quality.py app/src/main/assets/library
```

`repair_library_footnotes.py` 默认仅扫描，默认报告写入 `.generated/footnote-repair-report.json`。
`--apply` 才修改书库，重复执行不会新增重复注释。提交的报告记录本次修复量；再次扫描的新增量应为 0。

全库注释审计通过，书库质量审计错误为 0；既有年份、译者、简介等编辑待核对项与本次修复无关。
针对修复前后的数据逐项比较，确认原有注释、正文、目录和标识符得到保留。
最终书库共有8341条有正文的注释和2条缺文提示，合计8379处可点击引用。
新增测试确保缺文提示可以点击且仍出现在审计报告中，不会被统计为找回了原始正文。

Android 验证命令：

```text
gradlew testDebugUnitTest assembleDebug assembleDebugAndroidTest
gradlew connectedDebugAndroidTest
```

新增仪器测试加载第三卷第一章的九个真实引用，检查翻页和滚动渲染的上标、颜色及点击命中。
当前只完成仪器测试包编译；没有连接设备，因此未运行 `connectedDebugAndroidTest`。
Debug APK及仪器测试APK均构建成功，APK校验确认包含650部离线作品且没有网络权限。
